# Авто-паркур (Car Parkour / Obstacle Course)

Браузерная одиночная «полоса препятствий» в духе пользовательских карт GTA Online:
трасса висит в небе над городом и океаном, нужно доехать до финиша и не упасть.

## Запуск

```bash
npm install
npm run dev
```

Открыть http://localhost:5173

Продакшн-сборка: `npm run build`, результат в `dist/` (статический сайт, пути относительные —
работает из любой подпапки).

## Онлайн-версия (GitHub Pages)

Игра публикуется бесплатно на GitHub Pages: **https://dotpointt.github.io/gta-car-parkour/**

- Workflow `.github/workflows/deploy.yml` собирает игру и выкладывает `dist/` при каждом пуше в `main`
  (или вручную: Actions → Deploy to GitHub Pages → Run workflow).
- Один раз в настройках репозитория: Settings → Pages → Build and deployment → Source: **GitHub Actions**.

## Управление

| Клавиша | Действие |
|---|---|
| W / ↑ | газ |
| S / ↓ | тормоз (и в заносе тоже), задний ход — только с места |
| A D / ← → | руль |
| Пробел | ручник; на скорости — начать дрифт (держать газ и руль) |
| W / S в воздухе | лёгкий наклон носа вниз / вверх |
| A / D в воздухе | крен (можно перевернуть машину обратно на колёса) |
| R | респаун |
| C | камера (близко / далеко / с капота) |
| Мышь (зажать) | обзор вокруг машины |
| M | звук |
| Esc | пауза |

Геймпад: RT — газ, LT — тормоз, левый стик — руль и наклон в воздухе, RB — ручник.

## Уровни

В меню два режима: **CASUAL** (трассы 1–12, лёгкие и средние) и **CHALLENGE** (трассы 13–30, сложные
и экстрим). Нажатие на режим запускает случайную трассу из него, после финиша «Следующая трасса» — снова
случайная того же режима. Уровень 1 — «Классика» (план, написанный вручную), остальные генерируются
процедурно из каталога препятствий: спуск, прыжок (в т.ч. сквозь винт), пропеллеры, винты-мельницы,
движущиеся платформы, маятники, прессы, карусель, петля. Уровень N детерминирован (одинаков у всех).
Рекорды хранятся по каждому уровню.

**Дрифт-комбо:** пока машина в заносе, жёлтый счётчик копит секунды (на 2, 4, 7, 11 и 16 с он
разгорается сильнее: «ХОРОШО», «КРУТО!», «ОГОНЬ!», «БЕЗУМИЕ!», «ЛЕГЕНДА!»). Смена стороны заноса комбо
не сбрасывает (0.5 с на перекидку). Когда дрифт кончился (или на финише), накопленное **вычитается из
времени заезда**. Падение сгорает комбо.

Цвета машины: сначала открыты 3, каждая новая пройденная трасса открывает ещё один (всего 8).

Проверка генератора: `npm run levels -- 200`. Как добавить препятствие — см. **AGENTS.md**.

## Техническая часть

- **Three.js** — графика (процедурная машина, трасса, небо, город, океан, частицы)
- **Rapier (WASM)** — физика твёрдых тел, 120 Гц с интерполяцией кадров
- **TypeScript + Vite**

Физика машины (`src/car/vehicle.ts`) — собственная raycast-модель:
подвеска пружина + демпфер + отбойник + стабилизаторы, шины по Pacejka с фрикционным кругом
и статическим трением (решатель последовательных импульсов), автомат КПП с кривой момента,
полный привод 40/60, аэродинамика и прижимная сила, контроль в воздухе как в GTA.

Повреждения (`src/car/damage.ts`) — деформация вершин кузова от ударов
(сила удара — изменение скорости в точке контакта), постепенное смятие лопастями,
трескающиеся и вылетающие стёкла, разбитые фары, отрывающиеся бамперы, капот, спойлер
и зеркала (улетают отдельными физическими телами), дым из-под капота.
